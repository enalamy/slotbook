# SlotBook

Консольное приложение для бронирования переговорных комнат. Позволяет вести расписание, находить свободное время и сохранять историю бронирований.

## Возможности

- Добавление комнат и создание часовых слотов.
- Поиск свободных слотов на дату по одной комнате или по всем сразу.
- Бронирование на имя сотрудника и отмена с освобождением слота.
- Просмотр истории и её выгрузка в CSV.
- Автоматическое сохранение данных между запусками.

## Установка

Понадобятся Python 3.13 или новее, Git и [uv](https://docs.astral.sh/uv/getting-started/installation/).

Склонируйте репозиторий и установите приложение:

```shell
git clone https://github.com/enalamy/slotbook.git
cd slotbook
uv sync --no-dev
```

## Запуск

Из папки проекта выполните:

```shell
uv run --no-dev slotbook
```

Откроется меню. Введите номер нужного действия и следуйте подсказкам. Для выхода выберите `0`.

## Как пользоваться

1. Добавьте комнату: укажите название и вместимость.
2. Создайте слот: введите ID комнаты и будущую дату со временем начала.
3. Найдите свободные слоты на нужный день.
4. Забронируйте выбранный слот, указав его ID и имя сотрудника.
5. При необходимости отмените бронь по её ID или выгрузите историю через пункт `8`.

При создании слота дата и время вводятся в формате `дд мм гггг чч`, например `20 10 2030 12`. Такой слот длится с 12:00 до 13:00. Для поиска достаточно даты: `20 10 2030`.

Каждый слот длится один час и начинается ровно в начале часа. На него может быть оформлена только одна активная бронь. После отмены слот снова становится доступным, а запись остаётся в истории. Бронировать и отменять можно только ещё не начавшиеся слоты.

В поиске нажмите Enter вместо ID комнаты, чтобы посмотреть свободное время во всех комнатах. При бронировании и отмене пустой ввод ID возвращает в меню.

Приложение использует локальное время компьютера; предполагается работа по московскому времени.

## Данные и отчёты

Состояние автоматически сохраняется в `exports/slobook.json` и восстанавливается при следующем запуске. Запускайте программу из папки проекта, чтобы она находила тот же файл данных.

Для экспорта истории выберите пункт `8` и введите имя CSV-файла. По умолчанию отчёт сохраняется в `exports/history.csv`. В него входят активные и отменённые брони с именами сотрудников, комнатами, временем слотов и датами создания и отмены. Перед перезаписью существующего отчёта программа спрашивает подтверждение.
